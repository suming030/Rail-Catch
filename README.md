# 🚄 레일캐치 (RailCatch)

> **매진된 기차에서도 취소표의 기회를 놓치지 않도록.**  
> 만차인 기차에서 취소표를 빠르게 찾아주는 AI 에이전트 창업 아이템의 소개 웹사이트입니다.

## 프로젝트 소개

레일캐치는 사용자가 출발역, 도착역, 출발 날짜, 선호 시간, 인원, 좌석 등급을 설정하면 AI 에이전트가 취소표 탐색과 예매 기회 안내를 도와준다는 **서비스 콘셉트**입니다.

- **문제**: 매진된 기차표를 얻기 위해 사용자가 반복적으로 검색하고 새로고침해야 합니다.
- **제안 가치**: 사용자의 조건을 기억하고 취소표 발생 시점을 모니터링해 예매 기회를 알려주는 경험입니다.
- **예상 비즈니스 모델**: 개인 프리미엄 구독, 기업 출장 관리 서비스 등 (검증 전 가설).

## 웹페이지 내용

- 문제 상황과 창업 아이디어 소개
- AI 에이전트의 예상 작동 흐름
- 핵심 차별화 포인트
- 인터랙티브 데모: 출발역·도착역·날짜·인원·좌석 종류 설정
- 수익 모델과 FAQ
- PC/모바일 반응형 디자인

## 실행 방법

브라우저에서 [`index.html`](index.html)을 열면 바로 동작합니다. 별도의 설치나 빌드 과정이 없습니다.

## GitHub Pages 배포

1. 이 저장소의 **`index.html`, `README.md`**을 GitHub 저장소의 **최상위 경로**에 업로드합니다.
2. GitHub 저장소에서 **Settings → Pages**로 이동합니다.
3. **Build and deployment → Source**를 `Deploy from a branch`로 설정합니다.
4. **Branch**를 `main`, 폴더를 `/(root)`로 지정하고 저장합니다.
5. 배포 완료 뒤 GitHub Pages 주소에서 웹페이지를 확인합니다. (반영까지 시간이 걸릴 수 있습니다.)

## 주의 사항

이 프로젝트는 **대학 과제용 프로토타입**입니다.

- 실제 KTX·SRT 서버에 접속하지 않습니다.
- 표시되는 좌석 탐색 및 취소표 발견은 **가상 데이터**로 진행됩니다.
- 실제 예약/결제 기능은 제공하지 않습니다.
- 향후 상용화를 위해서는 관련 철도 운영기관의 서비스 정책, 허용된 공식 연동 수단, 개인정보 및 결제 요건 등을 검토해야 합니다.

## 기술 구성

- HTML5 / CSS3 / Vanilla JavaScript
- 외부 패키지 및 서버 없이 단일 정적 페이지로 실행
